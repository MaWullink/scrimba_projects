# PaletteLab 🎨

A simple color scheme generator that uses The Color API. Pick a base color and the app generates a matching palette displayed on the page.

## Features

- Color picker input
- Fetches color schemes from an external API
- Displays generated colors with hex codes
- Responsive grid layout

## Built with

- HTML
- CSS
- JavaScript
- The Color API

## What I learned

- Working with APIs using fetch
- DOM manipulation
- Dynamically creating UI elements
