# Movie Watchlist App

A simple movie search and watchlist app built with JavaScript and the OMDb API.

## Features

- Search for movies by title
- View movie details (title, runtime, genre, plot)
- Add movies to a watchlist
- Watchlist persists using localStorage

## How it works

- Uses the OMDb API to fetch movie data
- Stores watchlist in an array
- Saves data in localStorage so it stays after refresh
- Renders movies dynamically using JavaScript

## Technologies

- HTML
- CSS
- JavaScript (Vanilla)
- OMDb API

## What I learned

- DOM manipulation
- Event delegation
- Fetch API and async/await
- Working with arrays and objects
- localStorage

## Setup

1. Clone the project
2. Open `index.html` in your browser
3. Start searching movies
